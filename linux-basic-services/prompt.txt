通用 Linux 基础服务安装脚本

目标环境
- 发行版：RedHat 系列（RHEL/CentOS/Rocky/Alma 等，systemd + yum）
- 运行身份：root（脚本启动时检查，非 root 直接退出）
- 服务管理：统一 systemctl enable --now（开机自启并立即启动）

1. YAML 配置文件（config.yaml）
```
yum:
  enable: true
  iso_path: /path/centos7.iso              # 离线 RPM 源 ISO（搭建对外 yum 源用的包）
  repo_dir: /var/www/html/yum-repo         # 对外仓库持久目录（ISO 内 RPM 拷到这里，httpd 长期对外）

nfs:
  enable: true
  data_path: /data/nfs                     # NFS 导出目录

ntp:
  enable: true
  # NTP 服务端开放给所有可达节点（监听所有接口，restrict default kod nomodify notrap nopeer noquery），不绑具体 IP、不限网段

dns:
  enable: true
  domain: test.com     # 要解析的域名（兼容旧写法 doamin）
  map_ip: xx.xx.xx.xx  # 该域名解析到的 IP
```

字段约定
- 每个服务都有 enable 开关，false 则跳过该服务。
- IP 类字段（dns.map_ip）必须为合法 IPv4，否则配置校验失败。
- dnsmasq 监听本机 IP 与 127.0.0.1（仍监听回环，便于本机自行把 DNS 指向本服务时使用）。
- 各服务在自身 deploy_* 中按需安装依赖（yum: httpd/createrepo；nfs: nfs-utils/rpcbind；ntp: ntp；dns: dnsmasq），不从配置读取。

2. 脚本实现（Python，install_services.py）
按配置驱动安装四类服务。每个服务严格走三阶段：安全前检查(check) -> 清理(cleanup) -> 安装(install)。
- check_*（安全前检查）：安装前校验配置值与运行环境是否安全（必填项、IP 合法性、ISO 是否存在等），失败即中断；dry-run 下跳过文件探测。
- cleanup：清理上一次残留（仅删带托管标记的片段；NTP 与 DNS 用起止标记整块替换），保证幂等可重复。DNS 托管块追加到主配置 /etc/dnsmasq.conf（配置行本身不带注释），清理时整块剔除再追加写回，绝不整文件删除主配置。
- install：安装包 → 写托管配置 → 启动并开机自启服务（NTP 另做启动后自检）。

各服务语义
- yum：先把本机 /etc/yum.repos.d/*.repo **移入** /etc/yum.repos.d.bk（目录不存在则创建；仅移动、不恢复）以离线安装 → 将 iso_path **拷贝**到 /mnt/iso（保留原文件，目录不存在则 mkdir -p）后 loop 挂载，并把该挂载**临时固化到 /etc/fstab** → 安装仓库服务端依赖（httpd/createrepo）→ 把 ISO 内 RPM 拷到 repo_dir 并 createrepo 生成元数据 → 配置 httpd 对外服务（监听地址：探测本机 IP > 0.0.0.0；仓库经 Alias /repo/ 暴露，即 http://<本机IP>/repo/）→ **校验** httpd 对外源（http://<本机IP>/repo/repodata/repomd.xml HTTP 可达）→ 校验成功后直接覆盖写 Base.repo 指向本机网络源（http://<本机IP>/repo/）、删除本地 ISO .repo、卸载本地源（umount -l /mnt/cdrom + 删除 /mnt/iso 拷贝）、**移除 fstab 记录**；原网络源 .repo 备份在 /etc/yum.repos.d.bk 不恢复。校验失败则中止并保留 fstab/挂载与 .bk 以便排查（重跑自动清理）。其它节点 .repo 写 baseurl=http://<本机IP>/repo/ 即可。
- nfs：yum -y install nfs-utils rpcbind → 创建 data_path 并 chmod +x → 向 /etc/exports 追加导出项（*(rw,no_root_squash,sync,no_subtree_check)）→ exportfs -r → systemctl enable rpcbind → systemctl enable nfs → systemctl restart rpcbind → systemctl restart nfs。
- ntp：安装 ntp → 写入 /etc/ntp.conf（server 127.127.1.0 iburst + fudge 127.127.1.0 stratum 10 作本机时间源；restrict default kod nomodify notrap nopeer noquery 标准受限默认，仍允许时间同步、禁止改配置与查询控制）→ 停用冲突的 chronyd → 启动 ntpd → **启动后自检** ntpdate -q <本机 IP>（探测失败退 127.0.0.1；仅查询不校时，失败仅告警不中断）。监听所有接口、不绑具体 IP、不限网段。
- dns：安装 dnsmasq → 托管配置写入主配置 /etc/dnsmasq.conf（address=/domain/ip + conf-dir=/etc/dnsmasq.d/,*.conf 启用 drop-in 目录 + 上游转发 server=<ip>；监听地址：探测本机 IP > 0.0.0.0，同时绑 127.0.0.1；托管配置以起止标记整块追加（配置行本身不带注释），清理时整块剔除，绝不整文件删除主配置）→ **不修改本机 /etc/resolv.conf**（仅作 DNS 服务端对外/对内提供解析，各机器含本机自行把 DNS 指向本机 IP 即可）→ 启动 dnsmasq。

命令行接口
- --config <path>：指定配置文件（必填）。
- --dry-run：只打印将要执行的命令，不触碰任何系统。
- --validate：仅校验配置值，通过返回 0，失败返回 2。
- --service <name>：只处理指定服务（yum|nfs|ntp|dns），不指定则处理全部启用服务。

安全与质量
- 所有 Linux 命令经统一执行器，--dry-run 下零副作用。
- 托管配置均带标记，cleanup 不乱删用户其它配置；改 /etc/ntp.conf 前先备份、可还原；**不修改本机 /etc/resolv.conf**（dns 仅作 DNS 服务端，由各机器自行配置指向本机 IP）。
- 无 PyYAML 时回退内置极简 YAML 解析器（仅支持嵌套映射，列表字段不被支持将被忽略，且会明确告警）。
