## 关键决策与坑

1. **CCE 节点禁装 docker/containerd.io**：与托管 containerd.service 冲突；走 build.sh 内置 nerdctl+buildkitd 路线。
2. **版本基线只按最新版**（用户拍板）：nerdctl >= 2.x（save 无 `--format`）、buildkit >= v0.34（`--containerd-worker` string 型）；不做旧版探测兼容。
3. **buildkitd 配置走默认路径 `/etc/buildkit/buildkitd.toml`**：build.sh 拉起时不带 `--config`，mirror 配置必须落在默认路径；已运行实例改配置不热生效，须重启。
4. **GitHub 直连慢（~85KB/s）**：二进制下载可能超前台通道时限，用远端脱离执行 + 日志轮询模式。
